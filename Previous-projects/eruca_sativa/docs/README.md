Project title: Rocket genome sequence

Project Co PIs: Dr. Luke Bell, Prof. Carol Wagstaff

Schools: Food Biosciences

Project objectives: The project aims to develop genetic resources for breeders and processors to create superior cultivars of rocket salad for nutritional and sensory traits. The requested bioinformatics support is uploading the reference sequence and annotation file to the European Nucleotide Archive (ENA) database. Obtaining accession/project number that can be used as a reference.

Bioinformatics tasks category: Genome sequence data upload

Milestones:

- Uploading a de novo reference genome sequence and accompanying annotation files to the European Nucleotide Archive.

Deliverables: (1) Uploaded Genome sequence and annotation files (2) ENA Accession Numbers

Project status: Completed
