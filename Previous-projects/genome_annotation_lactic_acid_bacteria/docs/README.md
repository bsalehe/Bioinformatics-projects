Project title: Selection of starters for and stabilisation of flavour-enhancing process in lafun production by lactic acid bacteria

Project Co PIs: Abosede Fawole, Dr Colette Fagan, and Dr Kimon Andreas Karatzas

Schools: Food Biosciences

Project objectives: The full genomic sequence of 8 lactic acid bacterial cultures from cassava fermentation which are highly important for various food products around the world was obtained from the first time.

The aim of the work is to annotate the full genome sequences of these strains, in order to identify genes that might be related with antibiotic resistance (such genes should be absent if isolates are to be used for food consumption)

Bioinformatics tasks category: Gennome Annotation, Antibiotic resistance gene (ARG)

Milestones:

- Finding suitable tools/pipeline for annotating 8 prokaryotic genomes.
- Annotate 8 bacteria genomes.
- Use available antibiotic resistance databases to search for antibiotic resistance genes that match with annotated/predicted genes.
- Identify antibiotic resistance genes.

Deliverables: (1) Annotated genomes (2) Table containing identified ARG;

Project status: Completed.
