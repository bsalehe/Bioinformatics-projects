Project title: Molecular characterisation of Palaeolithic soil and artefacts from the first settlers of Scotland

Project Co PIs: Dr. Alejandra Perotti, Dr. Catia Antunes
 Hafiz

Schools: Biological Sciences (SBS)

Project objective: The study aims to determine the taxonomic composition of DNA in the sediments and artefacts by isolating DNA fragments with hybridization capture using probes for various mitochondrial genomes. The bioinformatic support requested pertains to the design of the probes using Mr.Bait. We are seeking assistance on how to efficiently design probes that cover whole mitochondrial genomes.

Bioinformatics tasks category: DNA capture probes

Milestones:

- Installing tools (HiCapTools, Mr.Bait) (1 day)
- Designing mitochondrial capture probes with Mr.Bait (2 Days)

Delivery: A summary table of the probes or list of probes for species under investigation.
