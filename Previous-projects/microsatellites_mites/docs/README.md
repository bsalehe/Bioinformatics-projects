Project title: Microsatellite study for Dermatophagoides farinae

Project Co PIs: Riyad Hussein Aeban, Dr Alejandra Perotti

Schools: SBS

Project objectives: The aim of project partly is to compare each of the sequences obtained by PCR with the originals (including the primers in the flanking sequences) from the whole Genome Sequence of the mite (Dermatophagoides farinae). This work will be applied to trace evidence analysis for forensic research using mites that live in human homes.

Bioinformatics tasks category: Genious training

Milestones:

- Genious training to read and align, check the quality, length of the sequences

Deliverables: (1) Mapped sequences, (2) Identified microsatellites

Project status: Completed and signed-off
