## Background
There have been many suggestions that the microcephaly gene ASPM has been involved in the evolution of brain size – from primates, to the rest of mammals. However, because ASPM can drive brain size change in any direction, current approaches seeking a relationship between the rate of genetic evolution and brain size find no link. The project aimed to seek a relationship between the rate of brain size evolution (i.e. adaptation in any direction) and the rate of ASPM evolution – thus providing evidence (or lack thereof) for the suggestion that ASPM has driven adaptive changes in brain size during the course of mammalian evolution.

## Objectives
To collect and identify all available protein-coding sequences data for ASPM. Then the alignment of orthologous ASPM sequences across all mammals will be done. Thus, the specific objectives are:

To have a complete set of (as many as possible) orthologous sequences for ASPM across mammals.
To have a reproducible pipeline or set of steps that was used to identify these sequences. This would facilitate the collection of sequences for other genes and taxonomic groups. Ideally this pipeline would be semi-automated or a set of manual steps that was used.

These sequences will be used to generate optimum alignments using MUSCLE, visual trimming and Max Align. The alignments will then be used to calculate rates of codon evolution in PAML.
