Project title: Metagenomic analysis of wastewater treatment plant

Project Co PIs: Yasmin Saif (Visiting PhD Student from Quid-i-Azam University in Islamabad, Pakistan) and Prof. ian Jones

Schools: SBS

Project objective: To complete 16S based population analysis for the anaerobic digester timed samples which were collected in Pakistan. 

At Reading the DNA samples have been amplified for V3 and V4 regions of bacterial 16S and local cloning and sequencing has established that they contain diversity relating to the time of sample and the originating chamber of the reactor. Based on this 25 V4 amplicons were provided to SourceBioscience for library construction and illumina sequencing. As part of this the samples provided were barcoded before mixing and using one flow cell at 300bp paired end on the MiSeq. The SourceBioscience demultiplexed and quality checked the data.

The requested bioinformatics urgent support was to analyse the data obtained (denoising and diversity analyses) using QIIME2.

Bioinformatics tasks category: QIIME2 analysis

Milestones:
- Denoising 16S data using QIIME2 DADA2 plugin.
- Alpha and beta diversity analysis.

Deliverables: (1) QC data; (2) alpha and beta diversity plots and group significance; (3) feature tables; and (4) Rarefaction and taxa bar plots.

Project status: Completed and Signed-off.
