Project title: Effects of the Post-Harvest Distribution Environment on Stem End Rot Development in Avocado (Persea americana) Fruit

Project Co PIs: Jessica Fostvedt, Prof. Carol Wagstaff

Schools: Food Biosciences

Project objectives: Avocados are a lucrative crop which suffers from high economic loss due to postharvest disorders.  One such disorder, stem end rot, is caused by a variety of different fungal species.  The purpose of this analysis is to determine if the phenotype of the fungal pathogen is statistically correlated with the type of rot, or severity of rot symptoms, produced in the corresponding fruit.

Bioinformatics tasks category: Data pre-processing

Milestones:

- Data pre-processing/preparation for running Dice coefficient similarity.
- Write R-script for running Dice coefficient similarity 

Deliverables: (1) Pre-processed data (2) R-script

Project status: Completed and signed-off
